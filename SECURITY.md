# Security Policy

## Supported Versions

We are committed to providing a secure environment for all users of FitDownloader. 
Currently, the following versions of FitDownloader are actively supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| v1.1.x  | :white_check_mark: |
| v1.0.x  | :x:                |
| < 1.0   | :x:                |

## Reporting a Vulnerability

Security is a top priority for FitDownloader. If you discover a vulnerability or any security-related issue, please report it immediately. We appreciate your efforts to responsibly disclose your findings.

### How to Report

1. **Do not open a public issue.** Please avoid disclosing the vulnerability publicly until it has been addressed.
2. Please open a Draft Security Advisory or reach out directly to the repository maintainer on GitHub.
3. Include the following details in your report:
   - A clear description of the vulnerability.
   - Steps to reproduce the issue.
   - The version(s) of FitDownloader affected.
   - Any potential impact on users.

### Response Timeline

- We aim to acknowledge your report within **48 hours**.
- A preliminary assessment and timeline for a patch will be provided within **1 week**.
- Once a fix is verified, a security patch will be rolled out and the vulnerability will be documented securely.

Thank you for helping keep FitDownloader secure!
